# Cinema ticket price checker

A Simple C console application developed to practice conditional statements (`if`, `else if`) and logical operators (`&&`).

## Features

- Prompts the user to input their age.
- ***Under 12 years old:*** Displays the child ticket price (5 euros).
- ***Between 12 and 17 years old:*** Displays the youth ticket price (7 euros).
- ***18 years old or older:*** Displays the adult ticket price (10 euros).

## Tech Stack

- ***Language:*** C
- ***IDE:*** Visual Studio Code
- ***Compiler:*** GCC (MinGW)
